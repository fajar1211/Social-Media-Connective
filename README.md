# Content Hub Pro

Build a modern, simple, elegant, and easy-to-understand admin dashboard called "Social Media Connective Admin".

PRODUCT NAME

Social Media Connective Admin

This is an internal admin dashboard for managing and creating marketing content.

The dashboard is focused ONLY on:

Creating marketing content

Importing content

Reviewing content

Managing content status

Organizing content by platform and content type

Approving content

Do NOT turn this into a full social media management platform.

Do NOT add:

Social media analytics

Followers

Engagement analytics

Inbox / DM

Advertising management

Campaign performance

Social media publishing

Complex CRM functionality

The goal is to keep the dashboard simple, elegant, focused, and easy to understand.

IMPORTANT DESIGN PRINCIPLE

Do not over-design the dashboard.

The main user journey should be immediately obvious:

Create → Review → Submit → Approve

Secondary workflow:

Import → Review → Organize → Approve

The user should never feel overwhelmed by the interface.
